# To-Do-List-V2
A sleek, responsive, and modern To-Do List application inspired by the iOS aesthetic. Rebuilt from the ground up using **State-Driven Architecture** with Vanilla JavaScript, featuring persistent LocalStorage management and a dynamic CSS Variables color theme switcher.
# 📱 iOS-Inspired To-Do List App (v2.0)
## ✨ Key Features
- **State-Driven Architecture:** Uses `Array of Objects` as a single source of truth for all CRUD operations.
- **iOS-Inspired UI:** Features custom circular checkboxes with completion checkmarks and smooth dark mode styling.
- **Dynamic Color Switcher:** Allows users to switch between 5 custom glow themes (Purple, Electric Blue, Neon Pink, Rose Pink, Bronze).
- **Persistent Storage:** Saves tasks and theme preferences using `localStorage`.
- **Task Counter & Controls:** Real-time task counting and a "Clear All" option with confirmation logic.
- **Responsive Design:** Optimized for mobile screens and desktop devices.

## 🛠️ Built With
- **HTML5**
- **CSS3** (CSS Variables, Flexbox, Animations)
- **Vanilla JavaScript** (DOM Manipulation, LocalStorage, BOM)
